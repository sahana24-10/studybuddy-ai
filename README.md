# StudyBuddy AI Dashboard 🚀

An aesthetic, dark-velvet productivity workspace featuring a live AI assistant, interactive analytics, task management, and a Pomodoro tracking matrix.

## ✨ Features
* **Dynamic Analytics:** Real-time subject focus allocation (Polar Area) and energy cycle tracking (Line Chart).
* **Knowledge Vault:** Text notes with support for clipboard image/formula pasting.
* **Cozy Timer:** Integrated Pomodoro focus clock with session logging.
* **AI Assistant:** Seamless connection to a local backend assistant.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Grid/Variables), JavaScript (ES6), Chart.js, Lucide Icons
* **Backend:** Node.js / Python
